# CI/CD Pipeline com GitHub Actions
![CI/CD Pipeline](https://github.com/GustavoTeixeiraDev/ci-cd-pipeline-github-actions/actions/workflows/deploy.yml/badge.svg)


Projeto simples para demonstrar uma pipeline de integração contínua e entrega contínua (CI/CD) usando GitHub Actions.

## Tecnologias utilizadas
- Node.js
- Express
- Docker
- GitHub Actions

## Como rodar localmente

```bash
git clone https://github.com/GustavoTeixeiraDev/ci-cd-pipeline-github-actions.git
cd ci-cd-pipeline-github-actions/app
npm install
npm start
